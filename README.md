# ![CorkScrew](https://raw.githubusercontent.com/nivalox/CorkScrew/refs/heads/main/assets/images/corkscrew.png) CorkScrew

CorkScrew is an open-source Rokori Executor built with C++ and Smali, it has a real Lua Virtual Machine (VM) and a dedicated Lua execution environment.

📑 Features

- Home - Main application interface.
- Editor - Built-in script editor.
- Console - Execution output and logging.

⚙️ Technical Overview

CorkScrew is completely open source and written primarily in C++ and Smali.

Unlike projects that rely on simulated environments, CorkScrew features a real Lua VM with its own Lua execution environment.

📂 Project Structure

- Native components written in C++.
- Smali-based Android components.
- Integrated Lua Virtual Machine.
- Dedicated Lua environment.
